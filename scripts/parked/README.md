# 自绘象形 —— 已下架

这里是一整套自己画星官图形的工具：`plume.py`（羽/鳞/节的笔法）、
`glyphs.py`（31 套图形族）、`classify_cn.py`（308 个星官按名字归族）、
`build_figures.py`（生成 `web/figures.js`）、以及几个验收脚本。

**2026-08-19 下架。** 原因只有一条：画得不好看，不如不放。
判断是产品方下的，不是技术问题 —— 机制本身是通的：
骨点对齐实测最大偏差 0.0006（作图坐标系，A→B 距离为 1），
396 个星官 100% 有图，风格由生成器统一。

下架后西方 88 座全部使用 Stellarium 的现成插画
（南船与蛇夫的画本来就跨座，船底/船尾/船帆共用 `argonavis.webp`，
巨蛇座共用 `ophiuchus.webp`）；中国星官回到连线本身 ——
敦煌星图、苏州石刻里星官本来就是连点成线，没有插画，这不算缺失。

要复活：把这些文件移回 `scripts/`，跑 `build_figures.py` 生成
`web/figures.js`，再在 `web/engine.js` 的 `ensureFig()` 里恢复自绘分支。
下架之后页面已抽成引擎 + 配置，自绘应该作为一个配置项接进来
（比如 `CFG.figures`），而不是写死在引擎里。
